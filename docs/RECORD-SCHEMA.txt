CSR/1 custom binary, NOT standardized: magic bytes 43 53 52 01, then schema-version text. text = u32 little-endian UTF-8 byte length + exact bytes (max 65536); count = u32 little-endian (max 4096). Follow four count-prefixed sections in order: entities (tag 10 hex, id text, kind text); relations (11 hex, id text, subject_kind text, object_kind text); evidence (12 hex, id text, raw 32-byte SHA-256, locator text); assertions (13 hex, id text, subject text, predicate text, object, uncertainty, provenance, times). Object: 20 hex + entity-id text; 21 hex + boolean byte 00/01; 22 hex + text; 23 hex + i64 little-endian two's complement. Uncertainty: 00 unknown; 01 + u16 little-endian permille (0..1000). Provenance: asserted_by text; method byte 00 observed/01 reported/02 inferred; count + evidence-id texts. Times: event tag 00 null or 01 + i64; then record i64 and interpretation i64, all little-endian. Maps/references are unique and lexically sorted by decoded strings; assertions unique/sorted by id. Max complete payload 1048576 bytes. No padding, optional trailing sections, unknown tags, duplicate identifiers or alternate order. Preserve every field, validate after decode, reject incomplete/trailing data and unknown framing/schema version. Payload is standard padded base64 in offline text envelopes. This is a local typed record format, not generic CBOR, Protobuf, or a model-native interface.
