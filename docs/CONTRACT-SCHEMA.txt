Communications 0.1-draft facts: JSON object with exactly version, entities, relations, evidence, assertions. version is "0.1-draft". entities map id to {kind:string}. relations map predicate to {subject_kind:string,object_kind:string}; literal object kinds are boolean,text,integer, otherwise an entity kind. evidence map id to {sha256:64 lowercase hex digits,locator:string}; hash identifies exact original bytes, locator is an unfetched hint. assertions is an array of {id,subject,predicate,object,uncertainty,provenance,times}. object is {type:entity|boolean|text|integer,value:the corresponding id|bool|string|i64}. uncertainty is {kind:unknown} or {kind:confidence,permille:u16 in 0..1000}, a source report, not calibrated probability. provenance is {asserted_by:entity id,method:observed|reported|inferred,evidence:nonempty unique evidence ids}. times is {event_ms:null|i64,record_ms:i64,interpretation_ms:i64}, independent UTC epoch milliseconds. All references must resolve and kinds match. Unknown/duplicate fields, missing fields and duplicate assertion ids are rejected. Maps/references sort by string; assertions sort by id. Preserve exact text/Unicode, attribution, conflicts, uncertainty, all three times and evidence metadata; do not infer truth from provenance. JSON payload is UTF-8. This is a local structural contract, not a universal ontology or standard. Binary/base64 requires decoding before interpretation; no hidden-state access is implied.
